# Placement Portal (ASP.NET)

This is a web-based Placement Portal developed using ASP.NET and SQL Server.

## 🚀 Features
- Student Registration & Login
- Company Management
- Job Posting
- Apply for Jobs
- Admin Dashboard

## 🛠️ Technologies Used
- ASP.NET Web Forms
- C#
- SQL Server
- HTML, CSS, JavaScript

## 🔐 Security Note
Sensitive data like database connection strings are not included in this repository.
Use your own configuration in `Web.Release.config` or environment variables.

## ▶️ How to Run
1. Open project in Visual Studio
2. Restore NuGet packages
3. Configure database connection
4. Run the project

## 📂 Project Structure
- `/Admin` → Admin panel pages
- `/Student` → Student module
- `/Company` → Company module
- `Web.config` → Configuration file
